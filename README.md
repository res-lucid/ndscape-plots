# ndscape-plots: interactive maps of nested dichotomies

Interactive maps of nested dichotomies (NDs) for multiclass classification, from the paper [ndscape: a structural map of the nested dichotomy space](https://arxiv.org/abs/2610.18050) (Dix-Matthews, Hodkiewicz and Polpo, 2026). Each point is one ND, and the colour shows test accuracy or bootstrap prediction variance on six UCI datasets, or squared bias or variance in simulations with a known generating ND.

Site: https://res-lucid.github.io/ndscape-plots/ (the tutorial is at `/tutorial/`).

The maps are made with [ndscape](https://github.com/res-lucid/ndscape), a Python package for nested dichotomies (`pip install ndscape`, [PyPI](https://pypi.org/project/ndscape/)). The data and map coordinates are archived on [Zenodo](https://doi.org/10.5281/zenodo.20456943).
